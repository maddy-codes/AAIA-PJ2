# Academic Writer Instructions

## Overview
This skill helps in producing a high-quality academic report that meets the CSY3060 PJ2 requirements. It ensures the report follows the requested structure and maintains a formal academic tone.

## Workflows
1. **Structure Planning**: Outline sections (Abstract, Introduction, Literature Review, Methodology, Results, Discussion).
2. **Drafting**: Assist in writing clear and concise technical descriptions and analysis.
3. **Ethics Analysis**: Provide guidance on discussing ethical, legal, and societal implications of the proposed AI method.
4. **Polishing**: Review the draft for clarity, flow, and adherence to word limits.
