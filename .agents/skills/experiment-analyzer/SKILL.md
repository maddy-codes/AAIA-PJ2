# Experiment Analyzer Instructions

## Overview
This skill is dedicated to the experimental phase of the project, focusing on the TextWorldExpress framework and the comparative analysis of agent performance.

## Workflows
1. **Environment Setup**: Configure TextWorldExpress environments (e.g., Coin Collector, Cooking World).
2. **Metrics Tracking**: Record and analyze rewards, loss curves, and convergence rates.
3. **Visualization**: Generate learning curves and performance tables using tools like Matplotlib or Seaborn.
4. **Results Interpretation**: Critically interpret statistical results and compare variations against the baseline method.
